# Ability support matrix (Wahapedia)

Generated by scanning wahapedia_data/Abilities.json and wahapedia_data/Datasheets_abilities.json and matching against the current rules engine implementation (mostly in Unit and Wargear).

**Maintenance note:** whenever we implement support for new abilities (by name or by description/pattern), update this document to reflect the new supported/partial/missing status.

## Summary

- Core (global) abilities in Abilities.json: 11
- Ability IDs referenced by datasheets (Datasheets_abilities.json rows with ability_id): 46 unique
- Custom datasheet abilities (ability_id empty): 3376 rows / 1861 unique names

## Supported / partially supported mechanics (pattern-based)
These mechanics are currently recognized by searching ability names and/or descriptions for specific text patterns:

- Deep Strike
- Infiltrators
- Scouts
- Stealth
- Lone Operative
- Firing Deck
- Deadly Demise
- Feel No Pain
- Fights First
- Fight on Death
- Shoot on Death
- Gain CP on destroy (keyword-based / “enemy unit” patterns) (partial)
- Heal on destroy (regain lost wounds) (partial)
- Redeploy (post-deploy)
- Advance+Shoot (exact wording)
- Fall Back+Shoot (exact wording)
- Advance+Charge (exact wording)

Note: several mechanics (Advance+Charge/Shoot/Fall Back+Shoot) rely on exact wording like: eligible to ... in a turn in which it advanced/fell back. If the wording differs, the engine will miss it.
