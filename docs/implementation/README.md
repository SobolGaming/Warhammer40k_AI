This directory is full of implementation plans as an auditable record of what was done and why for the various feature implementations.

All implementation plans here should follow the same format and be named `<feature>_implementation_plan.md` where `<feature>` is a short lowercase kebab-case description of the feature.

They should be task checklist oriented documents with complete and clear criteria and evidence of completion. They should be written in a way that is easy to understand for future developers and should serve as a guide for how to implement the feature again in the future if needed.
